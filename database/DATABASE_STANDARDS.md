# Database Standards

## Table Naming
- Use lowercase
- Use singular names
- Use snake_case

## Column Naming
- snake_case
- Foreign keys end with _id

## Audit Columns
- created_at
- updated_at
- created_by
- updated_by
- version

## Soft Delete
- is_active
- deleted_at
- deleted_by

## Primary Keys
- BIGINT AUTO_INCREMENT

## Enum Values
- Uppercase
